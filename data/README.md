# Data

Download `cookie_cats.csv` from [Kaggle: Mobile Games A/B Testing](https://www.kaggle.com/datasets/yufengsui/mobile-games-ab-testing) and place it here.

| Column | Meaning |
|---|---|
| `userid` | Player ID |
| `version` | `gate_30` (gate at level 30, the live version) or `gate_40` (gate at level 40) |
| `sum_gamerounds` | Game rounds played in the first 14 days after install |
| `retention_1` | Played again 1 day after install |
| `retention_7` | Played again 7 days after install |

90,189 rows, one per player, no missing values.
